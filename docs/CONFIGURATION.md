# 設定とトラブルシュート

## 推論先

Base URLはOpenAI互換APIのルートです。例: `http://127.0.0.1:8000/v1`。ホストだけのURLには `/v1` を補完し、`/proxy/v1` のような既存のパスは保持します。URL内のユーザー名・パスワード、クエリ、フラグメントは受け付けません。

Model IDはサーバーが配信する正確な名前を使います。画面から一覧を取得するか、直接入力してください。APIキーが空ならAuthorizationヘッダーを送信しません。必要な場合はBearer形式で送ります。

接続テストはモデル一覧と短いテキスト推論を使います。「画像を確認」は青一色のPNGを送り応答を表示する簡易試験です。画像の受理と、複雑な立体の認識品質は別です。

画像と生成コードは設定した推論先へ送信します。別PCや外部サービスを指定すれば、そのPC / サービスにもデータが渡ります。アプリは別の分析・計測サービスへ送信しません。

## Qwen / vLLMでの確認条件

実測した配信名は `qwen38-flash-next`。サーバーの情報は `Qwen3.8-Flash-Next-NVFP4`、コンテキスト32,768トークン、vLLM `0.28.1rc1.dev496+gcd64c2dea` でした。これらは推論先が返した値で、アプリの必須モデル名・起動設定ではありません。

Reasoning effortは「API既定」（送信しない）、`none`、`low`、`medium`、`xhigh` から選べます。選択した値は生成時に次のvLLM拡張パラメーターで送信します（例は`medium`）。Qwen3.8-Flash-Nextが公表している段階は`low`、`medium`、`xhigh`で、`none`の受理やthinkingの無効化は保証されません。実測したサーバーでは`low`で動作を確認しました。

```json
{ "chat_template_kwargs": { "reasoning_effort": "medium" } }
```

初期値は「API既定」で、この追加パラメーターを送りません。推論先が選択値とこの拡張パラメーターに対応する場合にだけ選択してください。Base URLまたはModel IDを変更すると「API既定」へ戻ります。接続テストにはこの値を送らず、生成時に適用します。

ベンチマークは出力16,384、temperature 0.65、low、300秒を使用しました。ソースや画像を添えると、32,768トークンに収まらない場合があります。画像を減らす、入力を小さくする、サーバーに合う出力上限へ変更するなどで調整してください。

## 保存場所とポート

| 内容             | 保存先・寿命                                |
| ---------------- | ------------------------------------------- |
| APIキー          | Node.jsのメモリのみ。再起動で消去           |
| キー以外の設定   | `.local/settings.json`                      |
| 編集履歴         | ページのメモリ。プロジェクト保存でZIPに出力 |
| ダウンロード     | ブラウザのダウンロード先                    |
| 開発時の評価結果 | `.local/<実験名>/`                          |

公開用ソースアーカイブには `.local/` を含めません。既存のローカル設定は初期値より優先します。ポート変更例（PowerShell）:

```powershell
$env:PORT=4175
npm start
```

変更後は `http://127.0.0.1:4175` を開きます。リッスン先を外部公開する設定はありません。

## よくある問題

| 症状                          | 確認・対処                                                         |
| ----------------------------- | ------------------------------------------------------------------ |
| 接続できない                  | Base URL、推論サーバー起動、VPN、WS側ファイアウォールを確認        |
| 401 / 403                     | APIキーと推論先の認証設定を確認                                    |
| 429                           | 推論先の混雑が解消してから再実行                                   |
| 400                           | Model ID、画像対応、コンテキスト上限、low拡張対応を確認            |
| 応答がHTML / JSONでない       | Web画面ではなくAPIルートを指定しているか確認                       |
| `length` / 途中終了           | 入力を減らすか、サーバー上限内で出力設定を調整                     |
| Workerタイムアウト            | モデルを簡素化。必要な場合のみ期限を増やす                         |
| WebGL / OffscreenCanvasエラー | Chrome / Edge、ハードウェアアクセラレーション、GPUドライバーを確認 |
| GLBボタンが無効               | 生成中・モデル未作成・警告対象素材を確認。標準素材への変更を指示   |
| 過去の作品が消えた            | 保存済み `.qmodel` を読み込む。ページ履歴は一時保存                |
| `.qmodel` を開けない          | 形式・依存バージョン・サイズ上限を確認。自動移行は未実装           |
| セッション無効                | ローカルサーバー再起動後にブラウザを再読込                         |
| ポート使用中                  | 既存プロセスを確認し、別ポートで起動                               |

生成が止まった場合はプロンプト欄の「生成の詳細」を開いてください。受信済みのテキスト、上流が返した終了理由、失敗した段階を確認できます。生成コードは正常終了して検証が通るまで実行しません。

バグ報告にはOS、Node.js、ブラウザ、再現手順、エラーコードを添えてください。APIキー、内部ホスト名、機密画像を含むログは公開しないでください。
